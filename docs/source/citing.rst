Citing inference-tools
======================

If you use inference-tools in your work, please cite it using the following DOI, which
always refers to the latest released version of the package:

`10.5281/zenodo.1423551 <https://doi.org/10.5281/zenodo.1423551>`_

The DOIs for specific versions of the package can be found on the
`Zenodo record <https://doi.org/10.5281/zenodo.1423551>`_.

The following BibTeX entry can be used to cite the package:

.. code-block:: bibtex

   @software{inference_tools,
     author    = {Bowman, Chris and Hill, Peter and Leddy, Jarrod},
     title     = {inference-tools},
     publisher = {Zenodo},
     doi       = {10.5281/zenodo.1423551},
     url       = {https://doi.org/10.5281/zenodo.1423551}
   }
