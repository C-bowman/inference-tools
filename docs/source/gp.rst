Gaussian process regression, optimisation and inversion
=======================================================
The ``inference.gp`` provides implementations of some useful applications of 'Gaussian processes';
Gaussian process regression via the :doc:`GpRegressor <GpRegressor>` class, Gaussian process
optimisation via the :doc:`GpOptimiser <GpOptimiser>` class, and Gaussian process linear inversion
via the :doc:`GpLinearInverter <GpLinearInverter>` class.
